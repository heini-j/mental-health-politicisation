# Repository contents

This repository contains all code used in the Master's thesis project: 

*"Mental health on the political agenda: 
An exploratory analysis of party manifestos"*


The folder structure is as follows:

01 Data retrieval: Scripts for calling the MARPOR API and retrieving the manifesto documents

02 LLM Encoding: Code used for testing different large language models and finally classifying mental health content in the manifestos (from Google Colab)

03 Data preprocessing: Scripts for combining datasets, cleaning the data, missing value analysis, variable transformations and statistical analysis preparation. Also, script for gathering and summarising data from the classified manifestos

04 Statistical analysis: Scripts separately for descriptive statistics (including plots), models 1-2 (negative binomial regression, including robustness analysis), models 3-6 (negative binomial regression with fixed effects) and ANOVA

05 Plots: Plots included in the final paper
